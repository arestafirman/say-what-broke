## Entry

> Error: the database is fine. The query you wrote joined every table twice and is now legally married to the server.

## How it works

`main.ts` writes the fixed error message above to `/output/entry.txt` (115 characters, one line, no trailing newline). No network, no randomness, no clock — the output is identical on every run.
